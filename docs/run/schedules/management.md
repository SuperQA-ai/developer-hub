# Managing Schedules

From the Schedules list view you can manage all your active and past schedules.

## Actions

| Action | Description |
|---|---|
| **Pause / Resume** | Temporarily halt a recurring schedule without deleting it. |
| **Edit** | Modify any field including the Test Plan, environment, or recurrence type. |
| **Run Now** | Trigger an immediate execution outside the normal cadence. |
| **Delete** | Permanently remove the schedule. |

:::caution
Deleting a schedule does **not** delete the historical Test Runs it already produced. All past run data is preserved under **Run → Test Runs**.
:::
