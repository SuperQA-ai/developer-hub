# Slack Configuration

Detailed configuration options for Slack webhooks and channel routing.

## Event Subscriptions

Select which events should post a message in your Slack channels:
- **Test Suite Started**: Notify when a test run is initiated.
- **Test Suite Finished**: Post a detailed report card with pass/fail metrics.
- **Failures Detected**: Post an alert containing links to screenshots and recordings of failed tests.
