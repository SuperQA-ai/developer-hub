# Slack Integration Overview

Send real-time alerts and test execution summaries to your Slack channels.

## Features

- **Instant Notifications**: Ping channels immediately upon test run completion or failures.
- **Detailed Slack Cards**: Show summary metrics, environment details, and direct links to failed test runs in the Slack message.
- **Channel Routing**: Route notifications from different test suites to specific Slack channels.

## Setup Instructions

1. Under **Configure > Integrations**, select **Slack**.
2. Click **Connect to Slack** to authorize the SuperQA Slack App.
3. Choose the default channel for notifications.
4. Save the integration.
