# Mail Configuration

Detailed configuration options for SMTP settings and email lists.

## Notification Triggers

Configure when emails should be dispatched to your team:
- **On Failures Only**: Sends an alert only when a test run has failed tests.
- **On Test Run Complete**: Sends a complete summary report after every run.
- **Daily Digest**: Sends a daily compiled report at a designated time.
