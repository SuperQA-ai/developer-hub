# Jira Integration Overview

Integrate SuperQA with Jira to automatically create and track bug tickets from your failed test runs.

## Features

- **Automatic Defect Creation**: Automatically generate Jira issues when test cases fail.
- **Link Test Run to Jira Ticket**: View the full test execution history and results directly from within the Jira ticket.
- **Custom Mapping**: Map SuperQA severity weights and custom fields to Jira issue types, priorities, and components.

## Setup Instructions

1. Go to your Jira account settings and generate an API Token.
2. In SuperQA, navigate to **Configure > Integrations**.
3. Select **Jira** and enter your Jira Host URL, email address, and API token.
4. Test the connection and save the configuration.
