# Jira Configuration

Detailed configuration options for mapping Jira fields to SuperQA tests.

## Field Mapping

You can map SuperQA test case metadata to custom Jira fields:
- Map **Severity** to Jira **Priority**
- Map **Test Run ID** to a custom Jira label
- Map **Component** to Jira **Components**
